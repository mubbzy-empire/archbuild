# ArchVision Professional — Phase 5

Phase 5 deepens the BIM/CAD production core while keeping the canonical Building IR as the single source of truth.

## Included
- Professional wall-junction classification.
- Parametric opening-family metadata and richer frame/reveal behavior.
- Foundations tied to architectural walls and structural columns.
- Ceiling grid coordination generated from rooms.
- Site/estate plot, setback-envelope and road coordination geometry.
- Explicit routed discipline geometry for electrical, plumbing, drainage, HVAC and fire systems.
- Building IR documentation and structural design-intent sections.
- BIM production panel in the professional modeler.

## Scope
The application is architectural design/coordination software. Structural sizing, MEP sizing, code compliance and permit approval still require qualified professionals and jurisdiction-specific review.
