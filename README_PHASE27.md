# ArchVision Professional — Phase 27

## Professional Construction Documentation

Phase 27 adds a model-derived construction documentation layer to the canonical Building IR.

### Added
- Production drawing views: floor plans, site/estate plan, roof plan, reflected ceiling plan, elevations, sections.
- Production sheets with drawing numbers, title-block metadata, paper size, scale, revision, issue date and status.
- Model-derived room, door and window annotations.
- Door, window, room and material schedules.
- Associative documentation metadata so drawing regeneration is tied to the canonical model.
- Configurable paper size, drawing scale and issue status.
- Phase 27 validation and manifest export.

### Professional-use note
Phase 27 produces model-derived design documentation. It is not a substitute for professional checking, local code review, statutory approval or construction issue control. Drawing scales, dimensions, annotations and schedules should be reviewed by the responsible architect before issue.
