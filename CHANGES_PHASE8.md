# Phase 8 changes

## Associative authoring
- Added `phase8Systems.js` for hosted openings, wall edits, offsets, trim/extend, constraints and associative documentation.
- Opening metadata now records its host wall and level.
- Wall edits update hosted opening offsets and prevent openings from drifting outside wall returns.

## Documentation
- Added model-derived dimensions, wall/room/door/window tags, view definitions and drawing sheets.
- Added plan, front/rear/left/right elevation and two section view definitions.
- Added an MEP coordination sheet to the drawing set.

## Geometry
- Added opening detail geometry including door-swing graphics.
- Added roof-edge reference geometry.

## QA / BIM
- Added Phase 8 validation and manifest schema `archvision-bim-0.8`.
- Integrated Phase 8 into the main Building IR geometry pipeline.
- Added a dedicated DOCS panel to the professional modeler.
