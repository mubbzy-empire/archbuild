# ArchVision Professional Phase 3

This phase advances the project from a modeling workbench toward an architectural production workflow. The central Building IR remains the source of truth.

### New capabilities
- Structural coordination visualization
- Foundation/column/beam/roof support intent
- Drawing-sheet mode with front elevation, Section A-A and schedules
- Quantity summaries
- Material schedule export
- Stronger opening QA/repair

The implementation intentionally avoids claiming that schematic drawings are permit-ready or that derived structural elements replace an engineer's calculations.
