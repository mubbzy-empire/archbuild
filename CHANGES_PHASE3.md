# ArchVision Professional — Phase 3

## Architectural production/documentation layer

- Added a derived structural coordination system: strip foundations, pad footings, reinforced-concrete columns, ring beams and roof support members.
- Added structural visibility control in the professional 3D modeler.
- Added schematic elevation and section documentation views directly inside the workbench.
- Added door/window schedule display and material-schedule export.
- Added quantity summary and structural coordination summaries.
- Added overlap repair for hosted openings and safer validation around missing opening arrays.
- Preserved the canonical Building IR so Chat, Blueprint, Estate and manual modeling continue to share one model representation.

## Scope note
The section/elevation renderer is a documentation preview layer, not yet a certified construction-document engine. Exact code compliance, structural analysis, engineering calculations and permit-grade documentation remain later-stage work.
