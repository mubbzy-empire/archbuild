# ArchVision Professional — Phase 18

## Direct 3D Authoring

- Added `archvision-bim-1.8` schema.
- Added direct 3D transform metadata and deterministic Building IR transforms.
- Added Three.js `TransformControls` to the Professional Modeler.
- Walls can be translated directly in the 3D viewport; hosted openings remain attached through the canonical model.
- Components can be translated and rotated directly in 3D.
- Added construction-view modes: Architectural, Construction, Structure and MEP.
- Added 3D authoring QA and exportable Phase 18 manifest.
- Added construction-aware 3D metadata for wall layers and opening details.

## Architectural foundation

The canonical Building IR remains authoritative. The viewport gizmo is an editing interface; it does not become a second model.
